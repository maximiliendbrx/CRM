PERSONNALISATION

Paramètres

Affichage et sauvegarde

La sauvegarde automatique se fait dans ce navigateur quand le CRM est ouvert. Si le site est fermé à l’heure choisie, elle se fera à sa prochaine ouverture. Les sauvegardes locales de plus de 10 jours sont supprimées.

Sauvegardes

Les sauvegardes restent sur cet appareil et peuvent être perdues si les données du navigateur sont effacées. Téléchargez-les pour conserver une copie indépendante.

Chaque ZIP contient le code actuel et les données de la sauvegarde choisie. Pour publier, utilisez uniquement le dossier site : le dossier donnees-privees doit rester confidentiel.

Réinitialisation des données

Effacer les données du CRM après création d’une sauvegarde locale. Les paramètres et sauvegardes restent disponibles.

Synchronisation multi-appareils (Supabase)

Le mode local reste actif tant que Supabase n'est pas configuré. N'importez aucune donnée professionnelle sans autorisation.

Dans Supabase : Project Settings → API Keys. Utilisez uniquement la clé publishable ou anon, jamais la clé secrète ou service_role.
